À la fin de cette leçon, vous serez capable de :

---

# 📖 Introduction

En mécanique quantique, les états d'un système sont souvent représentés à l'aide de la **notation de Dirac**, aussi appelée :

```text
Notation bra-ket
```

Cette notation a été introduite par le physicien :

```text
Paul Dirac
```

---

# 🔹 Le Ket

Un état quantique s'écrit généralement :

```text
|ψ⟩
```

Cela se prononce :

```text
ket psi
```

Exemples :

```text
|0⟩
|1⟩
|ψ⟩
|ϕ⟩
```

Lecture :

```text
ket zéro
ket un
ket psi
ket phi
```

---

# 🔹 Le Bra

Le dual d'un ket s'écrit :

```text
⟨ψ|
```

Cela se prononce :

```text
bra psi
```

Exemples :

```text
⟨0|
⟨1|
⟨ψ|
⟨ϕ|
```

Lecture :

```text
bra zéro
bra un
bra psi
bra phi
```
